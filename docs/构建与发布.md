# OrbitCloud 构建与发布

仓库提供 **Windows 一键构建脚本**,可在 Windows 上交叉编译出
**Windows / Linux / macOS** 三个系统的二进制(amd64 + arm64),并可选打包。

## 1. 脚本一览

| 脚本 | 平台 | 说明 |
|---|---|---|
| `build/build.ps1` | Windows | 主脚本(PowerShell 5.1+),全参数化 |
| `build/build.bat` | Windows | 批处理入口(自动 Bypass 执行策略,推荐日常使用) |
| `build/build.sh` | Linux/macOS | 对等脚本(参数为 `--xxx` 风格) |

产物统一输出到 **`build/dist/`**(已加入 `.gitignore`),每个平台一个目录:

```
build/dist/
├── orbitcloud-windows-amd64-1.0.0/
│   ├── orbitcloud.exe
│   ├── sha256sums.txt
│   └── web/                  # 前端产物(启用 -Frontend 时)
├── orbitcloud-linux-amd64-1.0.0/
├── orbitcloud-linux-arm64-1.0.0/
├── orbitcloud-darwin-amd64-1.0.0/
├── orbitcloud-darwin-arm64-1.0.0/
└── build.log                 # 构建日志
```

## 2. 环境要求

| 依赖 | 用途 | 版本 |
|---|---|---|
| Go | 后端编译 | ≥ 1.25(与 go.mod 一致) |
| Node.js + npm | 前端构建(仅 `-Frontend` 时需要) | ≥ 18 |

后端为**纯静态交叉编译**(`CGO_ENABLED=0`,SQLite 用纯 Go 实现 glebarez/sqlite),
不依赖任何 C 工具链,Windows 上可直接产出 Linux/macOS 二进制。

## 3. 常用命令(Windows)

```bat
:: ① 默认:三系统 × amd64/arm64 后端,不构建前端,不打包
build\build.bat

:: ② 完整发布:后端 + 前端构建 + 打 zip/tar.gz 包,版本号 1.2.0
build\build.bat -Frontend -Package -Version 1.2.0

:: ③ 只编 Linux amd64(快速验证)
build\build.bat -OSes linux -Archs amd64

:: ④ 只检查环境(go/node 是否可用),不编译
build\build.bat -CheckOnly
```

### 参数说明(build.ps1)

| 参数 | 默认 | 说明 |
|---|---|---|
| `-OSes <列表>` | `windows linux darwin` | 目标系统 |
| `-Archs <列表>` | `amd64 arm64` | 目标架构 |
| `-Version <v>` | git tag 或 `dev` | 产物/包名版本后缀(自动去 `v` 前缀) |
| `-Frontend` | 关 | 同步 `npm run build` 前端,并拷入各包 `web/` |
| `-SkipFrontend` | — | 与 `-Frontend` 互斥 |
| `-Package` | 关 | 打包:Windows→`.zip`(Compress-Archive),Linux/macOS→`.tar.gz`(bsdtar,缺失回退 zip) |
| `-SkipPackage` | — | 与 `-Package` 互斥 |
| `-CheckOnly` | 关 | 仅环境检查 |

Linux/macOS 对等命令(`build/build.sh`):

```bash
./build/build.sh --frontend --package --version 1.2.0
./build/build.sh --os linux --arch amd64
```

## 4. 发布产物验证

编译完成后建议抽验:

```bash
file build/dist/orbitcloud-linux-amd64-1.0.0/orbitcloud        # ELF 64-bit
./orbitcloud --version                                         # 打印版本
./orbitcloud --help                                            # 打印用法
./orbitcloud -initConfig                                       # 生成配置
```

Windows 二进制同样可跨平台验证 `--version` / `-initConfig`(纯 Go,无系统调用差异)。

## 5. 版本管理建议

- 打 tag 时用 `git tag v1.2.0`,脚本自动取 tag 作为 `-Version`;
- `config.yaml → app.version` 与 `--version` 输出一致,发布时保持与 tag 同步。

## 6. 常见问题

| 问题 | 解决 |
|---|---|
| 脚本中文乱码 | 已自动 `chcp 65001`;或终端用 Windows Terminal |
| "禁止运行脚本" | 用 `build.bat`(Bypass);或 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| npm 被 PowerShell 拦截 | 脚本内部已用 `npm.cmd` |
| tar 不存在 | 自动回退 zip(仅影响 Linux/macOS 包格式) |
| go 不在 PATH | 安装 Go 1.25+ 并重启终端,或把 go.exe 目录加入 PATH |
