# OrbitCloud 开发指南

面向本仓库的二次开发 / 参与贡献者。阅读前建议先看 [架构设计](架构设计.md) 与 [API参考](API参考.md)。

## 1. 环境准备

| 依赖 | 版本 | 说明 |
|---|---|---|
| Go | ≥ 1.25 | 后端(零 CGO 可构建) |
| Node.js / npm | ≥ 18 / ≥ 9 | 前端(Windows PowerShell 下用 `npm.cmd`) |
| 对象存储(可选) | 任意 S3 | 未启动时把 `config.yaml` 的 `storage.driver` 改 `local` |

```bash
# 后端
go build -o orbitcloud .
./orbitcloud -initConfig
./orbitcloud --add-superadmin admin admin123456
./orbitcloud

# 前端(另开终端)
cd frontend
npm install
npm run dev            # http://localhost:5173,代理 /api → 127.0.0.1:8080
```

## 2. 代码结构与分层约定

```
main.go           入口:配置 → 初始化 → HTTP → 后台任务 → 优雅停机
config/           配置结构 + 内置默认配置(embed)
appinit/          初始化程序(配置/日志/DB/JWT/存储/协程池)
core/             全局单例(GlobalConfig/DB/JWT/Pool/Storage),最底层
common/           哨兵错误/统一响应/分页/校验
model/            GORM 模型
server/           业务层(包级函数)
api/              HTTP 层(路由/handler/中间件)
cron/             定时任务
flag/             命令行指令
log/              日志封装
utils/            桶名编码/采样 MD5/ByteRange/堆栈
frontend/         Vue3 前端
build/            构建脚本(详见 构建与发布.md)
docs/             文档
```

**铁律**:

- `core` 不 import 上层业务包(server/api/...),只放全局单例;
- `server` 为包级函数,内部直接访问 `core` 单例,不引入 gin 依赖;
- `api` 纯无状态:只做参数解析/鉴权/调用 server,把哨兵错误映射为 HTTP 状态码;
- 新增错误先注册到 `common/errors.go` 哨兵,再在 `common.HTTPStatus` 映射状态码;
- 对象键 = 文件记录 ID;桶名 = `utils.BucketEncoder(桶ID)`,禁止依赖文件名/路径。

## 3. 新增一个 API 的完整流程(示例:统计接口)

1. **model**(如有新实体):`model/xxx.go` 定义 GORM 模型,`appinit` 的 AutoMigrate 自动建表;
2. **server**:`server/xxx.go` 写包级函数,返回哨兵错误(`common` 别名),不碰 HTTP;
3. **api**:`api/xxx_api.go` 定义无状态结构体方法:
   - 解析参数(`c.ShouldBindJSON` / `parseIDParam` / `queryInt`);
   - 鉴权预检(参考 `precheckBucketWrite` / `permOwnerOrAdmin`);
   - 调 server → `common.Success(c, data)` 或 `respondError(c, err)`;
4. **路由**:`api/router_xxx.go` 注册(登录路由组挂 `AuthMiddleware`);
5. **文档**:同步更新 `docs/API参考.md` 与 README API 概览表;
6. **验证**:起服务后 curl / 前端页面联调。

## 4. 测试

仓库目前以 Go 单元测试为主(如 `core/storage_range_test.go`、`utils/range_test.go`):

```bash
go test ./...            # 全部包
go test ./utils/ -v      # 指定包
```

- 测试风格:纯函数/边界用例(table-driven),不依赖外部服务(DB/对象存储);
- 前端类型检查:`cd frontend && npm run typecheck`(构建脚本已内置)。

## 6. 常见开发任务速查

| 任务 | 位置 |
|---|---|
| 改默认配置 | `config/default.yaml`(embed,改后需 `-initConfig` 重新生成) |
| 加命令行指令 | `flag/enter.go`(`RunPreInit` = 无需初始化;`Run` = 需 DB) |
| 加定时任务 | `cron/`(启动时 `main.go` 调用 `cron.Start`) |
| 调权限判定 | `api/perm.go` + `model/enter.go` 的 `PermissionLevel` |
| 加存储驱动 | `core/storage.go`(实现 `ObjectStorage` 接口)+ `appinit/storage.go` 工厂 |
| 前端加页面 | `frontend/src/views/` + `frontend/src/router/index.ts`(守卫) |
| 加 API 模块 | 前端 `frontend/src/api/xxx.ts` 按 `http.ts` 的 Axios 实例写 |

## 7. 提交规范

- 提交前跑 `go build ./...` 与 `go vet ./...` 保证可编译;
- 更新 `docs/` 与 README 中受影响的部分;
- 变更行为 / 新增接口务必同步 API 文档,保持文档即契约。
