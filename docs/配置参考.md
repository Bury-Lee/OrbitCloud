# OrbitCloud 配置参考

> 配置固定从**工作目录 `./config.yaml`** 读取;缺失时自动用内置 embed 默认配置生成,
> `-initConfig` 可强制覆盖。**不做缺省值兜底**——配置缺失/非法即启动报错。
>
> 完整可配置项以 `config/default.yaml`(编译期 embed)为准,本文件是其逐项说明。

---

## 0. 环境变量覆盖(推荐生产使用)

| 环境变量 | 覆盖项 | 说明 |
|---|---|---|
| `ORBITCLOUD_JWT_SECRET` | `jwt.secret` | 生产必改,长随机串 |
| `ORBITCLOUD_DB_DSN` | `database.sources[0].dsn` | 生产必改,避免连接串落盘 |
| `ORBITCLOUD_S3_ACCESS_KEY` | `storage.access_key` | 生产必改 |
| `ORBITCLOUD_S3_SECRET_KEY` | `storage.secret_key` | 生产必改 |

---

## 1. `app` 应用基础

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `name` | string | `orbitcloud` | 应用名称 |
| `version` | string | `1.0.0` | 版本号,与 `--version` 输出一致 |
| `environment` | string | `dev` | `dev \| test \| prod`,写入启动日志 |
| `timezone` | string | `Asia/Shanghai` | 时区 |

## 2. `server` HTTP 服务

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `host` | string | `0.0.0.0` | 监听地址,生产按需收窄 |
| `port` | int | `8080` | 监听端口 |
| `read_timeout` | int | `1` | 读超时(分钟;`0`=不限) |
| `write_timeout` | int | `0` | 写超时(分钟;**下载为流式返回,建议保持 0**) |
| `idle_timeout` | int | `0` | 空闲超时(分钟;`0`=不限) |
| `max_header_bytes` | int | `1048576` | 最大请求头(字节) |
| `mode` | string | `debug` | `debug \| release \| test`;debug 下开启请求日志与响应调试日志 |

## 3. `jwt` 访问令牌

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `secret` | string | 示例值 | **生产必改**;建议 `ORBITCLOUD_JWT_SECRET` |
| `expire_minutes` | int | `720` | 访问令牌有效期(分钟,即 12h) |
| `issuer` | string | `orbitcloud` | 签发者(Verify 时校验) |
| `algorithm` | string | `HS256` | 签名算法 |

`refresh_jwt` 刷新令牌配置(独立签发密钥,留空由访问密钥派生):

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `expire_minutes` | int | `10080` | 刷新令牌有效期(分钟,即 7 天) |
| `issuer` | string | `orbitcloud` | 签发者(默认同 `jwt.issuer`) |

## 4. `storage` 存储引擎

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `provider` | string | `rustfs` | `minio \| rustfs \| s3 \| oss \| cos \| obs` |
| `endpoint` | string | `http://127.0.0.1:9000` | 单存储端点;多节点场景留空,由 nodes 逐节点指定 |
| `access_key` | string | `rustfsadmin` | S3 Access Key,**生产必改** |
| `secret_key` | string | `rustfsadmin` | S3 Secret,**生产必改** |
| `region` | string | `us-east-1` | 区域 |
| `use_ssl` | bool | `false` | 端点 http/https 切换 |
| `timeout` | int | `30` | 请求超时(秒) |
| `max_retries` | int | `3` | 最大重试次数 |
| `chunk_size` | int | `5` | 分片大小(MB):文件按此切分分发到不同节点;建议 1~64 |
| `min_replicas` | int | `2` | 每分片最少副本数,副本落在不同节点 |
| `driver` | string | `s3` | `s3` 分片入对象存储(生产推荐);`local` 写本地目录(开发,无需对象存储) |
| `repair_interval` | string | `30s` | 副本修复扫描周期 |
| `repair_concurrency` | int | `4` | 副本修复并发上限(防"修复风暴") |

## 5. `health` 节点健康检查

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `check_interval` | string | `5s` | 节点探测周期 |
| `fail_threshold` | int | `3` | 连续失败 N 次 → 节点标记 inactive(自动剔除,不再分配新写入) |

## 6. `pool` 协程池(agilePool)

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `max_workers` | int | `64` | 全局并发上限 |
| `queue_size` | int | `1024` | 任务队列容量,超出后提交方阻塞 |

## 7. `nodes` 存储节点列表

全局凭据/驱动取自 `storage` 段,节点可逐项覆盖(留空 = 继承):

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 节点 ID,**唯一** |
| `driver` | string | 覆盖 `storage.driver`(`s3` \| `local`) |
| `path` | string | s3 驱动:bucket 名;local 驱动:本地目录路径 |
| `endpoint` | string | s3 驱动必填:该节点 S3 端点 |
| `access_key` / `secret_key` | string | 覆盖全局凭据(留空继承) |
| `max_space` | int | 容量配额(GB;`0`=不限) |
| `enabled` | bool | 默认 `true`;`false` = 启动时不注册该节点 |

## 8. `database` 元数据库

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `source` | string | `sqlite` | `sqlite \| postgres`;列表项未指定时继承 |
| `charset` | string | `utf8mb4` | 字符集 |
| `log_level` | string | `warn` | GORM 日志级别:`silent \| error \| warn \| info` |
| `max_idle_conns` | int | `5` | 主库连接池(仅 `sources[0]` 生效) |
| `max_open_conns` | int | `20` | 同上 |
| `sources[]` | list | — | **写库(必填 ≥1,首个为主库,负责建表/审计)**;`dsn` 优先于 host/port 拼装 |
| `replicas[]` | list | — | 读库(可选);多读库负载均衡;`sqlite` 不支持读写分离 |

DSN 示例:

```yaml
database:
  source: postgres
  sources:
    - dsn: "postgres://orbitcloud:pass@127.0.0.1:5432/orbitcloud?sslmode=disable"
  replicas:
    - dsn: "postgres://orbitcloud_ro:pass@10.0.0.2:5432/orbitcloud?sslmode=disable"
```

## 9. `log` 日志

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `level` | string | `info` | `debug \| info \| warn \| error` |
| `format` | string | `text` | `json`(生产建议,便于采集)/ `text` |
| `output_path` | string | `""`(stdout) | 非空启用文件轮转:按日期建子目录,文件名取 时-分-秒 |
| `max_size` | int | `0` | 单文件大小切换(KB;`0`=仅按日期切换) |
| `db_level` | string | `""` | 日志入库最低级别;留空不入库(量大会膨胀,谨慎) |
| `retention_days` | int | `30` | 日志表保留天数,超期由定时任务分批清理 |

`output_path` 两种写法:

```yaml
log:
  output_path: "./logs"        # → ./logs/2026-08-05/orbitcloud-14-30-05.log
  # output_path: "./logs/app.log"  # → ./logs/2026-08-05/app-14-30-05.log
```

## 10. 生产最小改动清单(对照检查)

```yaml
jwt:
  secret: "<64位以上随机串>"            # 或 ORBITCLOUD_JWT_SECRET
storage:
  access_key: "<真实 Key>"             # 或 ORBITCLOUD_S3_ACCESS_KEY
  secret_key: "<真实 Secret>"          # 或 ORBITCLOUD_S3_SECRET_KEY
database:
  source: postgres
  sources:
    - dsn: "postgres://..."            # 或 ORBITCLOUD_DB_DSN
nodes:
  - id: node1
    endpoint: "https://s3.example.com" # 真实端点
```
